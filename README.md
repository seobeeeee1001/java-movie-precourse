- 영화
  - 제목
  - 상영 길이

- 상영
  - 상영 시간
  - 상영 날짜

- 좌석
    - 좌석 번호
    - 예약 상태
    - 등급
    - 상영

- 사용자
  - 포인트

- 예매
    - 상영
    - 좌석
    - 총 결제 금액

- 할인
  - 좌석 등급
  - 상영 시간
  - 상영 날짜

- 결제수단

    - 현금

## 구현 기능 목록

- 시스템 목표 : 영화 예매

1. 상영 id, 좌석 id, 결제 수단, 포인트 입력

2. 결제 금액 계산
    - 2.1 좌석 등급에 따른 요금
    - 2.2 날짜 조건 확인 ( 매월 10일, 20일, 30일에 상영되는 영화는 10% 할인된다)
    - 2.3 시간 조건 확인 (오전 11시 이전 또는 오후 8시 이후에 시작하는 상영은 2,000원이 할인)
    - 2.4 포인트 사용에 따른 할인 적용
    - 2.5 결제 수단에 따른 할인 적용 (신용카드 결제는 5% 할인 , 현금 결제는 2% 할인)

3. 예약 객체 생성
   - 3.1 상영, 좌석, 총 결제 금액 정보 포함
   - 3.2 좌석 예약 상태 업데이트
